A. Minimum Cost Network Topology

You are commissioned to architect a resilient high-throughput optical transit backbone connecting N primary server clusters, indexed from 1 to N. There are M bidirectional fiber conduits candidate routes available. Each conduit i directly joins node ui and node vi with optical deployment latency weight wi.

To prevent single-cluster packet congestion, a critical structural limitation is enforced: the central ingress cluster (Node 1) must hold a tree degree strictly less than or equal to K in the chosen connected backbone topology. All other nodes can maintain arbitrary degree connectivity as long as the entire cluster forms a connected spanning tree.

Determine the minimum aggregate conduit deployment weight required to form a valid connected spanning tree satisfying this degree constraint. If it is impossible to construct a spanning tree meeting the criteria, output -1.

verified Input Constraints
Nodes (N) 2 ≤ N ≤ 10⁵
Conduits (M) 1 ≤ M ≤ 2×10⁵
Latency / Weight 1 ≤ wᵢ ≤ 10⁹

Constraints guarantee the candidate graph is simple, undirected, and may contain disconnected partitions initially.

Sample 1 Walkthrough:

Node 1 degree limit is K = 2. The optimal Spanning Tree picks edges (3,4) with cost 1, (2,3) with cost 2, and edge (1,2) with cost 3. Node 1 has degree 1, which strictly adheres to ≤ 2. Aggregate latency = 1 + 2 + 3 = 6.

class UnionFind:
def __init__(self, n):
self.parent = list(range(n + 1))
self.rank = [0] * (n + 1)

def find(self, u):
if self.parent[u] != u:
self.parent[u] = self.find(self.parent[u])
return self.parent[u]

def union(self, u, v):
root_u, root_v = self.find(u), self.find(v)
if root_u == root_v: return False
if self.rank[root_u] < self.rank[root_v]:
root_u, root_v = root_v, root_u
self.parent[root_v] = root_u
if self.rank[root_u] == self.rank[root_v]:
self.rank[root_u] += 1
