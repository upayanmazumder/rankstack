Architecture

Records and live state

  • FastAPI validates requests and writes related documents in MongoDB transactions.
  • Redis stores session keys, rate-limit counters, and leaderboard sorted sets.

Advanced queries

Five aggregation questions

  • Who leads a contest by score?
  • How do scores differ by problem difficulty?
  • Which verdicts appear in each contest?
  • How many distinct problems did each user solve?
  • How many submissions and members does each team have?
  • Indexed lookups use IXSCAN for problems and participant submissions.
