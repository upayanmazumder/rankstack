1. Database Implementation

1.1 Collections

CollectionKey fields
usersname, email (unique), passwordHash, role, totalScore, teamIds[]
teamsname, memberIds[], totalScore
conteststitle, startTime, endTime, status, createdBy, problemIds[], participants[]
problemscontestId, type (mcq/coding/subjective), difficulty, points, + type-specific fields
submissionscontestId, problemId, submittedBy{refType,refId}, status, score

1.2 Relationships

  • Contest → Problems (problems.contestId)
  • User/Team → Submission (submissions.submittedBy)
  • Submission → Problem (submissions.problemId)
  • Team → Users (teams.memberIds), with a back-reference users.teamIds
  • Contest → Users/Teams (contests.participants, embedded ref array)

Each collection has a $jsonSchema validator. problems uses a oneOf clause so mcq/coding/subjective documents enforce different required fields at the database level.

3. Advanced NoSQL Features

3.1 Aggregation pipelines (5)

#PipelineResult (sample)
1Leaderboard per contest — group by submitter, sum score, sort desc {totalScore: 40, refId: ..., refType: 'user'}
2Avg score per problem, grouped by difficulty {difficulty: 'hard', avgScorePerProblem: 18.17}
3Submission count by status, per contest {status: 'correct', count: 8}
4Distinct problems solved (correct) per user {name: 'Angie Henderson', distinctProblemsSolved: 4}
5Team performance — $lookup teams → submissions via memberIds {name: 'Team Lavender Trial', totalScore: 195.0}
# pipelines[4] — team performance ($lookup excerpt)
{"$lookup": {"from": "submissions", "let": {"memberIds": "$memberIds"},
  "pipeline": [{"$match": {"$expr": {"$and": [
      {"$eq": ["$submittedBy.refType", "user"]},
      {"$in": ["$submittedBy.refId", "$$memberIds"]}]}}}],
  "as": "memberSubmissions"}}

3.3 Transactions (multi-document, on a replica set)

  • Create submission + increment problems.attemptCount atomically
  • Update submission status/score + update submitter's totalScore atomically
  • Add/remove team member + update users.teamIds back-reference atomically
with client.start_session() as session:
    with session.start_transaction():
        db["submissions"].insert_one(doc, session=session)
        db["problems"].update_one({"_id": problem_id},
                                   {"$inc": {"attemptCount": 1}}, session=session)
Evidence: problem.attemptCount before=7 after=8   |   user.totalScore before=90 after=100
